# Presentation

Put the final slide deck (`.pptx` / `.pdf`) in this folder. Suggested outline (10 to 12 slides, about 10 minutes plus a demo):

1. **Title**: project name, team, Batch F, registration numbers
2. **Problem**: too much news to read; the need for fast and faithful summaries
3. **Objectives**: summary, headline, key points, sentiment, entities, quality checks
4. **Architecture**: the pipeline diagram from `capstone/README.md`
5. **Classical NLP**: spaCy NER, VADER sentiment, statistics
6. **LLM summarization**: prompt design, JSON mode, guard against invented facts
7. **Extractive baseline**: scoring method; why it is useful offline
8. **Evaluation**: reference-free metrics and the results table
9. **Live demo**: `streamlit run code/app.py` (screenshots in `capstone/screenshots/` as a backup)
10. **Testing and GitHub workflow**: pytest, CI, issues, branches and pull requests
11. **Limitations and future work**
12. **Team contributions and Q&A**
