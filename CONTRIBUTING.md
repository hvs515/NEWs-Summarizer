# Contributing

1. **Open an issue** with one of the templates: Dataset Collection, Model Development, Testing, Documentation or Deployment. Assign it to yourself.
2. **Create a branch** from `main`: `git checkout -b feature/<short-name>`.
3. **Commit small, meaningful changes**, for example `Add entity coverage metric`.
4. **Run the tests** before you push: `python -m pytest -q`.
5. **Open a pull request** with the PR template and link the issue (`Closes #N`).
6. **Get a review** from a teammate. Merge only after approval and green CI.
